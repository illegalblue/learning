    Phase 3: CD Pipeline with Ansible (Build → Push → Deploy)

    ← Back to Phase 2

    Goal

    Automate deployment of your application:

    • Build Docker images
    • Push to registry
    • Deploy to staging (Node1) using Ansible
    • Ensure repeatable, idempotent deployments

    Prerequisites

    • Phase 2 completed
    • Jenkins pipeline working
    • Node1 VM accessible via SSH
    • Docker installed on Node1 (or will be installed via Ansible)

    Deployment Flow

    Merge to main
     ↓
Jenkins CD Pipeline
     ↓
Build Docker Image
     ↓
Push to Registry
     ↓
Run Ansible Playbook
     ↓
Deploy to Node1 (Staging)

    Step 1 — Prepare Node1 (Target Server)

    Create Deployment User

    SSH into Node1:

    ssh <your-user>@node1

    Create user

    sudo adduser deployer

    Add sudo access

    sudo usermod -aG sudo deployer

    Setup SSH directory

    sudo mkdir -p /home/deployer/.ssh
sudo chown -R deployer:deployer /home/deployer/.ssh
sudo chmod 700 /home/deployer/.ssh

    Add Public Key

    On your control machine:

    ssh-copy-id deployer@node1

    Disable password auth (basic security)

    sudo nano /etc/ssh/sshd_config

    Set:

    PasswordAuthentication no

    Restart:

    sudo systemctl restart ssh

    Checklist

    • [ ] Can SSH without password
    • [ ] Non-root user created
    • [ ] Sudo access works
    • [ ] Password login disabled

    Step 2 — Setup Ansible Control

    Run this on your Ansible container / host

    Create inventory

    ansible/inventory.ini

    [node1]
node1 ansible_host=<NODE1_IP> ansible_user=deployer

    Test connection

    ansible -i inventory.ini node1 -m ping

    Checklist

    • [ ] Ansible can reach Node1
    • [ ] SSH works without password

    Step 3 — Ansible Playbook (Server Setup)

    ansible/setup_node.yml

    - name: Setup Node1
  hosts: node1
  become: yes

  tasks:
    - name: Install Docker
      apt:
        name: docker.io
        state: present
        update_cache: yes

    - name: Enable Docker
      systemd:
        name: docker
        enabled: yes
        state: started

    - name: Add deployer to docker group
      user:
        name: deployer
        groups: docker
        append: yes

    Run

    ansible-playbook -i inventory.ini ansible/setup_node.yml

    Checklist

    • [ ] Docker installed on Node1
    • [ ] Docker service running
    • [ ] User can run docker

    Step 4 — Docker Registry Setup

    Use Docker Hub (simplest)

    Login

    docker login

    Tag image

    docker tag fastapi-app <dockerhub-username>/fastapi-app:latest

    Push

    docker push <dockerhub-username>/fastapi-app:latest

    Checklist

    • [ ] Image available in registry
    • [ ] Pull works from Node1

    Step 5 — Ansible Deployment Playbook

    ansible/deploy.yml

    - name: Deploy FastAPI App
  hosts: node1
  become: yes

  vars:
    image_name: "<dockerhub-username>/fastapi-app:latest"

  tasks:
    - name: Pull latest image
      docker_container:
        name: fastapi-app
        image: "{{ image_name }}"
        state: started
        restart_policy: always
        ports:
          - "8000:8000"

    Run

    ansible-playbook -i inventory.ini ansible/deploy.yml

    Verify:

    curl http://<NODE1_IP>:8000/health

    Checklist

    • [ ] Container running on Node1
    • [ ] App accessible via browser/curl
    • [ ] Restart works automatically

    Step 6 — Jenkins CD Pipeline

    Update your Jenkinsfile:

    stage('Build Docker Image') {
    steps {
        sh '''
        docker build -t fastapi-app .
        '''
    }
}

stage('Tag Image') {
    steps {
        sh '''
        docker tag fastapi-app <dockerhub-username>/fastapi-app:latest
        '''
    }
}

stage('Push Image') {
    steps {
        sh '''
        docker push <dockerhub-username>/fastapi-app:latest
        '''
    }
}

stage('Deploy to Node1') {
    steps {
        sh '''
        ansible-playbook -i ansible/inventory.ini ansible/deploy.yml
        '''
    }
}

    Checklist

    • [ ] Pipeline runs on main
    • [ ] Image built and pushed
    • [ ] Ansible deploy triggered
    • [ ] App updated automatically

    Step 7 — Basic Security

    • Do NOT hardcode credentials

    • Use:

    • .env files

    • Ansible Vault (next phase)

    Checklist

    • [ ] No secrets in repo
    • [ ] SSH key-based auth only
    • [ ] Non-root deployment

    Step 8 — Idempotency Check

    Run deployment twice:

    ansible-playbook -i inventory.ini ansible/deploy.yml

    Expected:

    • No errors
    • No duplicate containers
    • Clean restart if needed

    What You Built

    You now have:

    • Full CD pipeline
    • Automated deployment using Ansible
    • Real staging environment
    • Repeatable infrastructure setup

    Final Checklist

    • [ ] Node1 configured via Ansible
    • [ ] Docker image built & pushed
    • [ ] Deployment automated
    • [ ] App accessible externally
    • [ ] Pipeline fully working
